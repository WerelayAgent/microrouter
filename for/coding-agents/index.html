Why it fits

Change the connection, then get back to the task.

The client still sends an ordinary OpenAI-compatible request. MicroRouter handles the approved route and returns the serving provider and cost with the response.

One balance
Prepaid credits cover eligible calls across the published model catalog.
Failover
Eligible requests can be retried against another healthy provider.
Request receipt
The final serving provider and request cost are returned with the response.
